A wooden text field for hero names, custom quests and custom actions.

**You provide:** `label`, `placeholder`, `value`/`onChange` (or `defaultValue`), `hint`, `multiline`.

- Text is 18px so phones do not zoom on focus.
- Labels ask a question in the barkeep's voice: "What's your hero called?"
- Placeholders show a fun example, never instructions.
- Border is `edge` (3:1 or better on wood); focus is a `focus` ring.
